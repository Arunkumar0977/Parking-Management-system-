Parking Management System
Project Description
This Parking Management System is a simple C-based console application that helps manage vehicle parking in a structured way. It allows users to log in and perform operations like adding, deleting, and viewing parked vehicles.

Features
User Login System: Ensures authorized access.
Vehicle Entry: Supports car, cycle, and bus parking.
Parking Fee Calculation: Charges are applied for each vehicle type.
Show Parking Status: Displays total vehicles and collected amount.
Delete Vehicle Entry: Allows the removal of specific vehicle entries.
Clear All Data: Resets parking records.
Interactive Console UI: Uses a menu-driven approach.
Technologies Used
C Programming Language
Standard I/O Library (stdio.h)
String Handling (string.h)
Console Input (conio.h)
Dynamic Memory Handling (stdlib.h)
